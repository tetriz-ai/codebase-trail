# Codebase Trail 0.1.0

Initial preview release. Turn committed repository code and merged pull requests into practice questions, then check your understanding against cited source evidence.

## Added

- Local browser app for component design, service dependencies, repository topology and merged GitHub PR practice, selected in one dropdown.
- Source citations, structured validation and model review before a question is published.
- Saved answers, feedback, notes and history import/export for revisiting attempts.
- Local model endpoints, supported model APIs and authenticated Claude Code/Codex CLI adapters, with explicit source-egress policies.
- Three complete offline examples and an extractor SDK for adding source conventions.
- GitHub release tarball and checksum-verified macOS/Windows runtime installers; no npm registry publication.

## Fixes and tooling

- Repository-neutral architecture practice routes, APIs and checkout settings; legacy names remain supported.

- Credential-variable hints follow the selected generator and reviewer providers.
- Model calls avoid redundant CLI version probes; preparation details expose generation and review timings and attempt counts.
- Updated XML parsing, ESLint and TypeScript tooling retain Node.js 20 declarations and a compiler API compatibility package for mutation tests.
- Contributions use the project license without a DCO sign-off or separately signed agreement.

## Validation boundaries

Offline unit tests pass on Node.js 20, 24 and 26. Browser, coverage, mutation, example, packaging and macOS Apple Silicon installer checks pass with isolated profiles and synthetic fixtures.
Native Windows and macOS Intel installation remain unverified. No live-provider latency improvement or model accuracy is claimed.

## Compatibility and privacy

This is a maintained pre-1.0 preview. Public commands, configuration and history/export formats may change in minor releases; see the [changelog](../../CHANGELOG.md) for release history.

Install Git separately. Source and direct tarball installations require Node.js 20+ and npm; the runtime installers download Node.js 24.22.1 with npm into your user folder.

Remote APIs and signed-in model CLIs receive bounded repository evidence. Citation validation and model review do not prove an explanation correct or measure learning gains. Uncommitted edits and untracked files are outside the source snapshot.
