    Advanced model controls

    Defaults work for most models. Change these only if the provider reports a limit or an unsupported response format.

    Increase if your model is slow.
    Values below 4,096 are raised automatically; the model uses only the tokens it needs.
    Set only when your endpoint does not report it.
    Use the model’s published output limit.
    Off may be unavailable for models that require reasoning; Codebase Trail then requests low reasoning. A truncated generation retry gets at least 8,192 tokens.
    Models that require reasoning use low effort when Off is unavailable. Review starts with at least 2,048 tokens; a truncated retry gets at least 4,096.
    Values below 2,048 are raised automatically to leave room for reasoning and JSON.
    Other options (expert JSON)

    These options are for provider-specific fixes. Use JSON strings for modes and numbers for limits. Credentials do not belong here.

    • reasoningMode: auto, openai, openrouter, or disabled.
    • tokenParameter: auto, max_tokens, or max_completion_tokens.
    • temperatureMode: auto, enabled, or disabled.
    • retryMaxOutputTokens and reviewTimeoutMs: positive numbers; timeouts use milliseconds.

    Example: {"reasoningMode":"openrouter"}. The form reports an unsupported key or value when you save.
